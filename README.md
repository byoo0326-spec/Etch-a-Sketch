# Etch-a-Sketch

**Below is the psuedocode for this project:**

1. 16x16 screen of square divs created by flexbox
2. Create a function that changes the color of a square div when called
3. Setup EventListeners for every square that trigger that function
4. Add a centered button above the squares which takes user input
5. Use that number as width and height (# of divs) dimensions for a new layout with a maximum of 100
